# Quarantined 2026-09-22

These are the A3/A5 decks built on a CANDU-6 37-element bundle mistaken for an
RBMK channel (3.85 cm zirconium calandria tube = 33% of the cell, 37 pins in
4 rings, 45% graphite, zirconium number densities 10x too low, no
self-shielding). They produced a void coefficient of -183 to -621 pcm/%void.

`ACOMPO_negative_void` is the 11 MB MULTICOMPO exported from that cell. It
encodes a negative void coefficient. Do not use it.

Superseded by `5.1/Dragon/data/rbmk_cell_a3.x2m`, `rbmk_a5_void.x2m` and the
shared `rbmk_proc/RbmkLib.c2m`. See PROGRESS.md.

Kept as evidence, not as a starting point.
