# Orphaned `.access` scripts

Moved here 2026-09-23. These 21 scripts had no matching `.x2m` in `Dragon/data/` — every
one of their decks is in `quarantine/` (the `rbmk_cell_sph_*` lineage, ~25 variants
generated by permuting tracking modules against a template that carried one unfixed
`SEQ_BINARY` declaration error).

Each file is a copy of the generic DLIB_99 linker with a different usage string. They are
kept, not deleted, only because the parent quarantine README treats this whole lineage as
evidence. Nothing references them.
